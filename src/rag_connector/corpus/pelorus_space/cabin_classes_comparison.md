# Cabin class comparison — Pelorus Voyages

| Feature | Pioneer (PCL) | Navigator (NCL) | Pathfinder (PFL) |
|---|---|---|---|
| **Berth type** | Shared cabin, up to 4 passengers, same gender | Private berth (solo) or private shared cabin (companions) | Private luxury suite |
| **Dining** | Shared dining hall, fixed schedule | Flexible — main hall any service time, or cabin delivery | Private dining room, on-demand any hour |
| **Personal mass allowance** | 12 kg | 18 kg | 25 kg |
| **Equipment rental credit** | None included; rental at standard rate | 1× rental credit per voyage | 2× rental credits per voyage |
| **Standard shore excursions** | Not included; purchased separately | Included at all stops | Included at all stops |
| **Caldera Rim hike (Olympus Mons)** | Not available (Pathfinder class only) | Not available (Pathfinder class only) | Included; fitness test still required |
| **Glass floor tour (Venus)** | Add-on; separate purchase | Included | Included |
| **Gondola descent (Venus)** | Add-on; separate purchase + separate medical clearance | Add-on; separate purchase + separate medical clearance | Priority booking access; add-on, separate purchase + separate medical clearance |
| **The Leap (Ceres)** | Add-on; age 16+, waiver required | Add-on; age 16+, waiver required | Add-on; age 16+, waiver required |
| **Lunar Golf Links** | Add-on; equipment included in excursion price | Included | Included |
| **Medical bay priority** | Standard (queue-based) | Standard (queue-based) | Priority access |
| **Orbital Points multiplier** | 1× (base rate) | 1.5× | 2× |
| **Companion discount eligibility** | Set by loyalty tier, not cabin class | Set by loyalty tier, not cabin class | Set by loyalty tier, not cabin class (both passengers must be Pathfinder tier) |
| **Same-day upgrade (departure day)** | To NCL or PFL; cash or credit card only — Orbital Points not accepted | To PFL; cash or credit card only | N/A (already highest class) |

## Notes

- All three classes travel on the same vessel and visit identical stops. Class affects onboard experience and inclusions, not itinerary.
- Mass allowance is per passenger, not per cabin. Two Navigator passengers in the same cabin each have 18 kg.
- "Add-on" means separately purchased regardless of cabin class. The gondola descent at Venus is an add-on at all classes; Pathfinder receives priority booking access only.
- The Caldera Rim hike fitness test is conducted at Mars Colony 1 and is separate from standard medical clearance. Every passenger taking the hike must pass it.
- Equipment rental credits are redeemable at any stop. Unused credits do not carry over to future voyages.
